# NeoBoard WordPress Theme

Тема лежит в `wp-content/themes/neoboard`.

## Что реализовано

- Многостраничный сайт доски объявлений в стиле неоморфизм.
- Кастомный тип записей `nb_listing` и таксономия категорий.
- Архив объявлений с фильтрами по запросу, городу и категории.
- Страница отправки объявлений с модерацией (`pending`).
- Страницы «О проекте» и «Контакты».
- Адаптивная сетка без налезания кнопок на контент.

## Быстрый старт в WordPress

1. Скопируйте папку `wp-content/themes/neoboard` в установку WordPress.
2. Активируйте тему в админке.
3. Создайте страницы и назначьте шаблоны:
   - Главная (статическая `front-page.php`)
   - Подать объявление (`page-submit-listing.php`)
   - О проекте (`page-about.php`)
   - Контакты (`page-contact.php`)
4. Создайте меню и назначьте в области `primary` и `footer`.
5. Добавьте категории объявлений в разделе «Категории объявлений».
